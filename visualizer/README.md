# nanotrace visualizer

WebGPU-based visualization tool for nanotrace files.

## Development

```bash
npm install
npm run dev
```

## Building

```bash
npm run build
```

The built files will be in the `dist/` directory.

## Deployment

The visualizer is automatically deployed to GitHub Pages at [aikitoria.github.io/nanotrace](https://aikitoria.github.io/nanotrace) on every push to main.
